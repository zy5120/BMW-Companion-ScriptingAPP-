# BMW Companion

隐私优先的 BMW 只读车况小组件（Scripting App）。

作者：@厦门硬骨头
部分逻辑参考 Scriptable BMW 小组件作者：@没打伞
仅限个人学习使用，请尊重原作者代码，勿直接抄袭。

## 功能

- 短信验证码 / 密码登录（第三方 nonce 兼容服务 + 图形验证码自动识别）
- 真实车况：油量 / 续航 / 总里程 / 四轮胎压 / 油耗 / 门窗锁状态 / 停车位置 / 车辆告警
- 官方真实车辆图片（VIN + token）
- 多车账号切换
- 四种桌面组件尺寸，排布参考 bmw-linker
- 大号组件原生 Apple 地图显示停车位置（约 200 米、固定居中）
- 最近同步时间展示

## 使用

1. 将本项目作为 Scripting App 的脚本项目打开。
2. 打开脚本 → 设置 → 连接 BMW → 阅读并同意 nonce 披露 → 输入手机号（86 开头）→ 短信验证码登录。
3. 登录后车况页与桌面组件显示你的真实车辆数据。
4. 多车账号在 设置 → 连接会话管理 中切换车辆。

## 说明 / 依赖

- 登录依赖第三方 nonce 兼容服务 `m.qqtlr.com`（与 bmw-linker 同款）。
- 登录风控头含作者固定值 + 随机 x 兜底（参考 bmw-linker getSliderCaptcha）。
- 官方车辆图依赖有效会话与 VIN。
- 坐标直接使用 BMW 后台返回值，不做坐标系转换。
